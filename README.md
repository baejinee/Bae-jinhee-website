# 배진희 Bae Jin Hee — 작가 홈페이지

```
index.html    화면 구조 + 동작 (수정할 일 거의 없음)
style.css     색·글꼴·여백 (맨 위 :root 만 고치면 전체가 바뀝니다)
data.js       ★ 내용은 전부 여기에 있습니다
편집기.html    ★ 코드 안 만지고 내용을 고치는 도구
images/       작품·전시 전경·작가 사진 93장 (모두 작가님 원본)
preview.html  전체를 한 파일에 담은 미리보기 (확인용. 올리지 않아도 됩니다)
```

## 구성

```
첫 화면 ─ 한국어 / English 선택
소개
작품 ─ 연작마다  서문 → 낱개 작품 → 전시 전경
        Dispace(2016– ) → 경_계(2019– ) → Re;lation(2024– )
건축 공간 ─ 별도 구역. 성당 커미션 9건 (2018 → 2022)
협업 ─ 영화 《청설》 조명 · 기념품 제작 · Collaboration Art Work
이력
연락처 + 메일 보내기
```

작품 사진은 **잘라내지 않고** 같은 크기의 틀 안에 넣어 보여줍니다.
가로 작품이든 세로 작품이든 원래 비례가 유지되면서 격자는 반듯하게 맞습니다.

순서는 전부 **과거 → 최근**입니다. 새 작업은 각 배열의 **맨 아래**에 추가하세요.

## 마우스 커서

마우스를 쓰는 기기에서는 **화살표가 아예 사라지고** 빛만 따라다닙니다.
손전등을 비춘 것처럼 가운데가 환하고 가장자리로 갈수록 부드럽게 번집니다.

- 어두운 첫 화면 — 따뜻한 흰빛의 웅덩이
- 밝아진 뒤 — 흰 벽에 떨어진 색빛. 가운데에서 바깥으로 **하늘 → 보라 → 분홍**

두 상태는 같은 빛이고, 스크롤에 따라 자연스럽게 섞입니다.
가운데 작은 흰 점이 실제로 가리키는 지점이라 누를 곳을 놓치지 않습니다.
(빛은 조금 늦게, 점은 빠르게 따라와서 손전등을 휘두르는 느낌이 납니다.)

빛의 색을 바꾸시려면 `style.css` 의 `.lumen.glow`(어두울 때)와
`.lumen.cast`(밝을 때) 안의 색 값을 고치면 됩니다.

손가락으로 쓰는 화면과 '동작 줄이기' 설정에서는 나타나지 않고,
그때는 보통의 화살표가 그대로 보입니다.

## 언어

첫 화면에서 **한국어 / English** 를 고르면 사이트 전체가 그 언어로만 보입니다.
(전에는 두 언어를 함께 보여줬는데, 화면이 복잡해져서 선택 방식으로 바꿨습니다.)
고른 언어는 브라우저에 기억되고, 상단 바의 **KO / EN** 으로 언제든 바꿀 수 있습니다.

`data.js` 의 모든 항목에 `ko` 와 `en` 이 있습니다. 한쪽을 비워두면
그 언어에서는 채워진 쪽이 대신 나옵니다.

## 내용 고치는 법 — 두 가지

### 방법 1. 편집기 쓰기 (권장)

압축 푼 폴더에서 **`편집기.html` 을 더블클릭**하면 열립니다. 인터넷 없이도 됩니다.
홈페이지와 같은 순서(기본 → 첫 화면 → 소개 → 작품 → 건축 공간 → 협업 → 이력 → 연락처)로
내용이 쭉 펼쳐져 있고, 위쪽 줄로 원하는 구역에 바로 갈 수 있습니다.

**글자 고치기** — 고치고 싶은 글자를 그냥 누르고 치면 됩니다.
따로 저장 버튼을 누를 필요 없이 바로 반영됩니다.
국문과 영문이 좌우로 나란히 있어 빠진 곳이 한눈에 보입니다.

**사진 다루기** — 사진마다 아래에 버튼 세 개가 늘 보입니다.

| | 하는 일 |
|---|---|
| **바꾸기** | 다른 사진으로 교체 |
| **옮기기** | 다른 작품·구역으로 이동 (찾기 칸에 이름을 치면 바로 나옵니다) |
| **빼기** | 이 사진만 빼기 |
| 끌어다 놓기 | 순서 바꾸기 (맨 앞이 목록에 보이는 **대표** 사진) |
| ＋ 사진 추가 | 뒤에 더 넣기. **컴퓨터에 있는 사진을 여러 장 끌어다 놓아도** 들어갑니다 |

**잘못 건드렸으면 되돌리기.** 오른쪽 위 «되돌리기» 버튼 또는 `Ctrl` + `Z`.
사진 관련 동작은 40번까지 되돌아갑니다.

**처음 한 번, 사진 폴더를 연결해 두세요.** 오른쪽 위 «이미지 폴더 연결» 을 누르고
`images` 폴더를 고르면, 그 뒤로는 «바꾸기» 를 눌렀을 때 갖고 있는 사진이 전부
썸네일로 떠서 눈으로 고를 수 있습니다. (파일이 어디로 올라가지 않습니다. 이름만 읽습니다.)

**줄 늘리고 줄이기** — 작품·전시 전경·이력 등 모든 줄에 `↑` `↓` `삭제` 가 있고,
구역 끝에 «+ 추가» 가 있습니다.

**다 고쳤으면 — «전체 복사» 가 가장 간단합니다.**
맨 아래 «전체 복사» → GitHub 에서 `data.js` → 연필 아이콘 → `Ctrl+A` → `Ctrl+V` →
**Commit changes**. 1~2분 뒤 사이트에 반영됩니다.

컴퓨터에 파일로 두고 싶으시면 «data.js 내려받기» 로 받아 저장소 폴더의 `data.js` 에
덮어쓰셔도 됩니다. 옆의 «미리보기 열기» 로 실제 화면을 확인할 수 있습니다.

새 사진을 쓰셨다면 그 파일을 `images/` 폴더에도 같이 복사해 넣으세요.
사진 자리가 «파일 없음» 으로 보이면 폴더에 그 이름의 파일이 없다는 뜻입니다.

※ 편집기로 저장하면 지금 `data.js` 에 달린 국문 주석은 사라집니다.
   나중에 직접 코드를 고치실 생각이면 원본을 한 부 따로 보관해 두세요.

## 사진을 더 넣는 법

### 작품 한 점에 사진 여러 장 (상세 화면)

`images` 배열에 계속 추가하면 됩니다. 첫 장이 목록에 보이는 대표 이미지이고,
눌러서 열리는 상세 화면에 나머지가 이어서 나옵니다.
썸네일 오른쪽 아래에 `+2` 처럼 장수 표시가 자동으로 붙습니다.

```js
{ title: 'Our Light', ko: '', medium: 'mixed media', size: '가변크기', year: '2024',
  images: [
    'images/our-light.jpg',      // 대표
    'images/our-light-b.jpg',    // 상세
    'images/our-light-c.jpg'     // 계속 추가
  ] },
```

### 전시 전경

연작마다 `views` 배열이 있습니다. 캡션은 국문/영문 둘 다 적습니다.

```js
views: [
  { image: 'images/view-relation-7.jpg',
    caption: { ko: '《RE;lation》 공간운솔, 인천, 2024',
               en: 'RE;lation, Space Unsoll, Incheon, 2024' } }
]
```

**※ 지금 들어 있는 전시 전경 캡션은 포트폴리오 PDF에서 추정한 것입니다.**
확실한 건 《빛을 바치다》(2021)와 《Dispace》(2022) 정도이고,
나머지는 "전시 전경, 연도"로만 적혀 있으니 확인해서 고쳐 주세요.

## 이미지 권장 규격

가로 1,600px, JPEG 품질 82 안팎. 파일 이름은 영문·숫자·하이픈만 씁니다.
파일이 없으면 회색 자리표가 들어가고 깨진 아이콘은 뜨지 않습니다.

모두 작가님이 보내주신 원본에서 만들었습니다 (가로 1,600px).
가로·세로가 1,000px 에 못 미치던 사진은 모두 덜어냈습니다.
아직 포트폴리오 PDF에서 뽑은 것이 5장 남아 있습니다 — `이미지-목록.md` 참고.

원본 사진이 있으면 **같은 파일 이름으로 덮어쓰면** 바로 반영됩니다.
세로로 찍은 사진의 회전 정보(EXIF)는 처리할 때 반영했으므로 그대로 두셔도 됩니다.

## 메일 받기 — 설정이 필요합니다

**지금 상태로는 메일이 오지 않습니다.** 방문자가 양식을 채우고 보내기를 누르면
그 사람의 메일 앱이 열릴 뿐이라, 거기서 한 번 더 보내야 도착합니다.
중간에 그만두면 문의가 사라집니다.

사이트 안에서 바로 받으시려면 (무료, 5분):

1. formspree.io 가입
2. **New Form** → 받을 주소를 `baejinhee.art@gmail.com` 로
3. 발급된 주소(`https://formspree.io/f/xxxxxxxx`)를 복사
4. `data.js` 의 `contact.formEndpoint` 에 붙여 넣기 (편집기 → 연락처 → 맨 아래 칸)
5. 첫 전송 때 formspree 가 확인 메일을 보냅니다. 링크를 눌러 승인하면 끝

무료 요금제는 월 50건까지입니다.

## 논문 링크

이력의 **연구** 항목에 `url` 칸이 있습니다. 여기에 DBpia 나 KCI 주소를 넣으면
제목을 눌러 논문 페이지로 갈 수 있습니다.

PDF 를 직접 올리지 않는 이유 — 학술지 논문의 저작권은 학회에 있어서,
원문을 홈페이지에 올리면 문제가 될 수 있습니다. 링크가 안전하고,
학술 DB 에 실려 있다는 것 자체가 신뢰를 줍니다.

찾는 법: dbpia.co.kr 또는 kci.go.kr 에서 본인 이름이나 논문 제목으로 검색 →
논문 페이지 주소를 복사 → 편집기의 **이력 → 연구** 줄에 있는 «링크» 칸에 붙여넣기

## 올리는 법 (GitHub Pages)

저장소 `baejinee.github.io` 에 `index.html`, `style.css`, `data.js`,
`편집기.html`, `images/` 를 올립니다. 파일 이름이 같으므로 기존 것을 덮어씁니다.

컴퓨터에서:
1. 저장소 열고 **Add file → Upload files**
2. 압축 푼 폴더에서 위 항목들을 통째로 끌어다 놓기
3. **Commit changes**
4. 1~2분 뒤 `baejinhee.art` 새로고침

예전 파일 중 `admin.html`, `netlify.toml`, `_redirects`, `script.js`, `robots.txt`,
`sitemap.xml` 은 이제 쓰지 않습니다. 그냥 두셔도 사이트에는 영향이 없습니다.

## 사진 톤

올리는 사진은 모두 한 번 톤을 맞춰 두었습니다. 나란히 놓았을 때 어떤 것만
튀어 보이지 않게 하려는 것이고, 다음 두 가지를 다르게 다룹니다.

- **작품 사진** — 거의 건드리지 않습니다. 색이 곧 작업이니까요.
  화이트밸런스만 아주 살짝(±3% 한도), 밝기는 ±7% 안쪽.
- **전시 전경 · 건축 공간 · 협업** — 흰 벽·바닥의 밝기를 서로 맞춥니다.
  공간 사진의 흰 기준 편차가 ±25 에서 ±13 으로 줄었습니다.

어두운 사진(밤의 촛대, 어두운 전시장)은 어두운 채로 둡니다. 검은 부분도
건드리지 않아서 유리의 깊이가 사라지지 않습니다.

새 사진을 넣으신 뒤 톤을 다시 맞추고 싶으시면 말씀해 주세요.
